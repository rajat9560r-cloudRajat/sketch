# Sketch

A simple sketch/drawing web app built with HTML, CSS, and JavaScript.

## Features
- Draw with a mouse or touch input
- Pick colors from preset swatches or a custom color picker
- Adjust brush size
- Use an eraser
- Undo the last drawing action
- Clear the canvas
- Save your drawing as a PNG

## Run locally
1. Clone the repository
2. Open `index.html` in your browser, or run a local web server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Project files
- `index.html` — app layout
- `style.css` — styling and layout
- `script.js` — drawing logic and toolbar behavior

## Deployment
This project is ready to be hosted on GitHub Pages using the included workflow in `.github/workflows/static.yml`.
